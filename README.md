🐾 Pokémon Universe Gallery

A simple and responsive Pokémon gallery built using HTML, CSS, JavaScript, and PokéAPI.

This project was created to practice working with APIs, JavaScript fetch(), JSON data, DOM manipulation, search, filtering, and responsive web design.

🌐 Live Demo

https://github.com/khushimaithani/pokemon-gallery/tree/master

✨ Features

🔎 Search Pokémon by name

🏷️ Filter Pokémon by type

🃏 Pokémon cards with images, names, and types

🔄 Interactive card design

➕ Load more Pokémon

📱 Responsive design for mobile and desktop

⚡ Pokémon data fetched dynamically from PokéAPI

🚫 No React or other frameworks used

🛠️ Technologies Used

HTML5 — Website structure

CSS3 — Styling and responsive layout

JavaScript (ES6+) — API requests, DOM manipulation, search and filtering

PokéAPI — Pokémon data and images

🔗 API

This project uses the free PokéAPI.

API endpoint:

https://pokeapi.co/api/v2/pokemon

No API key is required.

📁 Project Structure

pokemon-universe-gallery/
│
├── index.html
├── style.css
├── script.js
└── README.md

index.html

Contains the structure of the webpage, including the heading, search/filter controls, Pokémon container, and buttons.

style.css

Contains the complete styling of the website, including the Pokémon cards, layout, colors, animations, and responsive design.

script.js

Handles:

Fetching Pokémon data from PokéAPI

Converting API responses to JSON

Displaying Pokémon cards

Searching Pokémon

Filtering by Pokémon type

Loading more Pokémon

🚀 How to Run Locally

Clone the repository:

git clone https://github.com/khushimaithani/pokemon-universe-gallery.git

Open the project folder in VS Code.

Open index.html using Live Server.

Or simply open index.html in a browser. A local server is recommended when working with APIs.
